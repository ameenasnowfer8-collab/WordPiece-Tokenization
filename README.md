# WordPiece Tokenizer

A simple implementation of a WordPiece Tokenizer using Python and the Hugging Face Tokenizers library.

## Features

- Trains a WordPiece tokenizer using education-related text data
- Tokenizes input text into subword tokens
- Generates token IDs
- Creates a vocabulary file
- Saves the trained tokenizer as `tokenizer.json`

## Technologies Used

- Python
- Hugging Face Tokenizers
- WordPiece Tokenization

## Dataset

The project uses a small custom text dataset related to education and learning.
